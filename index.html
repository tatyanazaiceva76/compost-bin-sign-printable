Browser-local sign maker

Printable compost bin signs

Build a matching PDF sign set from accepted and excluded rules you have already verified with your own collector or operator. The tool lays out your text; it does not decide what belongs in a bin.

Three steps

  1. Enter each bin title and your confirmed accepted/excluded lines.
  2. Choose paper, orientation, measured sign size and copies.
  3. Confirm the rules, generate the shared preview/PDF layout, then download.

Method, privacy, limits and third-party licenses

Make one consistent, measured sign set

Enter one to eight bin titles, your own accepted and excluded lines, and the number of copies needed for each sign. Choose A4 or Letter paper, portrait or landscape orientation, and the sign width and height you measured. The result is one ordered PDF containing every requested copy, plus editable project JSON you can save and import later.

Preview and PDF use the same Noto Sans layout and trim-mark geometry. Text is never silently shortened or squeezed: unsupported characters, unsafe dimensions and content that will not fit are refused with an explicit error. Before posting a sign, print a test at 100%, measure the printed box, and confirm the wording with the collector or operator responsible for your location.

Project data stays in this browser. Packaged scripts and font bytes load from the same origin; the tool sends no project data to third parties and uses no accounts, analytics or persistent storage.
